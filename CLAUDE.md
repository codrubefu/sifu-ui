# Sifu UI

Read `AGENTS.md` for compact architecture, task entry points, commands and rules.
Use `docs/AI_GUIDE.md` when the task location is unclear. Follow local AGENTS.md
instructions in the domain you change.

Search relevant sections of `docs/project-rules-agent.md` for detailed conventions
and `docs/functionality-explainer-agent.md` for existing behavior; do not load both
in full for a narrow task. Update the explainer for changed screens, workflows,
API contracts, permissions, routes or localization namespaces.

The optional `.claude/agents/sifu-ui-dev.md` agent uses the same guidance. Ordinary
repository tasks do not require a subagent or a second architecture read.
